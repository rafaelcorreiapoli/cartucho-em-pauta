# Projetos automáticos do modo Calote

Decisões da discussão de 19/11/2026. Registro de design; os projetos abaixo ainda não estão implementados.

## Primeira seleção aprovada

Periodicamente, um projeto é aprovado sem votação, desconta seu custo do orçamento público e aplica um efeito à partida. A duração padrão da partida passa a ser de 12 minutos. A programação escolhida para os projetos é começar aos cinco minutos, com intervalo de 90 segundos: 5:00, 6:30, 8:00 e 9:30 de tempo efetivo de partida. A ordem é sorteada, sem repetição. Essa programação ainda precisa ser implementada.

Os itens são entregues primeiro no inventário. O excedente vai para o armário pessoal; se também não couber, cai no chão dentro do gabinete do jogador. Os custos e o percentual do reajuste continuam como propostas em discussão.

| Projeto | Efeito escolhido |
| --- | --- |
| Pacote Porrete | Distribuir um porrete para cada jogador. |
| Reajuste Emergencial de Subsídios | Aumentar os salários e, consequentemente, a despesa dos próximos pagamentos. |
| Programa Congresso Sem Dormir | Distribuir cinco energéticos para cada jogador. |
| PEC da Qualificação Parlamentar | Conceder dois pontos de atributo para cada jogador distribuir. |

Os salários continuam entrando diretamente nos cofres dos jogadores, conforme a dinâmica existente. Não são entregues em maletas. Os projetos automáticos são uma dinâmica do Calote, distinta da votação opcional de projetos.

O Programa Voz do Povo foi descartado. O megafone permite falar com jogadores independentemente da distância; não concede campanha ou popularidade.

## Backlog: Estatuto da Legítima Defesa do Mandato

Ideia aprovada para guardar, fora da primeira seleção: um projeto distribui bombas de fedor, financiadas pelo orçamento público. O item ainda não existe no jogo e precisa de design e implementação próprios antes de integrar qualquer projeto.

A intenção sugerida é criar confusão, atrapalhar a circulação e provocar suspeitas sobre quem está sabotando a arrecadação. Alcance, duração, efeitos concretos e formas de reação permanecem em aberto; nenhuma dessas regras está definida.
